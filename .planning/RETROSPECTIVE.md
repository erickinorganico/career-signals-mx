# Retrospective

## v1.0.0 — Investigación ENOE

Shipped 2026-09-28: five phases, 19 plans, 31 accepted requirements.

The project delivered source custody, defensible estimates, evidence-linked findings, offline research outputs and a publicly verified release. Exact hashes allowed reuse of unchanged numerical/R evidence while installed hosts, public assets and human readability were verified separately.

Independent review caught weak receipt binding, an API media-type mismatch and a temporary README encoding defect before final acceptance. Keeping the public payload frozen avoided unnecessary numerical reruns. Repeated packaging and administrative timestamp checks were inefficient; future runs should freeze UTF-8 bytes and use the tested CI wheel earlier.

Publication workflows must fail immediately on a failed prerequisite. An initial archival command followed a stale-verification rejection; active paths were restored, the verifier independently refreshed its report, canonical completion passed, and archival was repeated only after the five-phase readiness check passed. Phase paths were preserved through the supported no-archive-phases option because tests consume an evidence fixture there.

Native Sol workers handled bounded implementation and independent reviews. No separate paid inference was introduced; token or cost savings were not measured.
