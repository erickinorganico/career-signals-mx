# Phase 3 integration coverage decision

This analytical phase integrates local validated objects only. References to API assertions and integration tests do not authorize or introduce a remote service. The matrix is a scope decision; actual behavior must pass the plans' tests.

| capability | decision | reason |
|---|---|---|
| Accepted Phase 2 public v2 projection and aggregate audit | INTEGRATE | Validate interfaces, source/method references and numerical acceptance before constructing profiles. |
| Local coverage, comparability, claim and analysis packet interfaces | INTEGRATE | Deterministic complete-cell grids and evidence-bound templates; tested through current API outputs. |
| Reviewed geographic/classification evidence | INTEGRATE | Versioned catalog/concept signatures and evidence already recorded in the project; no automatic bridge activation. |
| Remote dataset or statistical API calls | OPT-OUT | Accepted local Phase 2 artifacts are the sole numerical inputs; no new source is required. |
| External language-model inference or ranking services | OPT-OUT | Canonical descriptive templates are deterministic; AGENTS excludes external inference and personal career ranking. |
| Hosted UI or backend service | OPT-OUT | The authorized deliverable is a local research pipeline and static publication. |
