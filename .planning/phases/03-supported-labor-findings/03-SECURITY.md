# Phase 3 — Security verification

This register carries the actual threat models authored in Plans 03-01, 03-02 and 03-03 into execution. It is not a passing security assessment. The configured threshold is high, with ASVS level 1 scoped to this local aggregate analysis pipeline; authentication and sessions do not apply.

## Trust boundaries

Accepted strict public estimates and aggregate coverage enter an evidence index and profiles. A reviewed definition registry and exact endpoint provenance govern descriptive comparisons. Typed, canonical Spanish claims and a strict analytical packet become the input to Phase 4 publication. No person rows, internal diagnostic estimate payloads, arbitrary prose, source activation or unchecked geography equivalence cross those boundaries.
