## Human review notes

The authorized `v1.0.0` release is recoverable by a public reader and every requirement is traceable to current accepted evidence.

## Execution

1. Require 05-02 `PASS`, clean CI at the exact target and a clean tree. Create the GitHub draft for `erickinorganico/career-signals-mx` at the frozen SHA with the exact allowlist. Upload, download into an isolated readback directory, and compare every name, size and SHA-256 to local approved bytes and remote digest where available. Record mismatches as `BLOCKED`; do not substitute preview-release assets silently.
2. With all local/independent/terms/license/privacy gates satisfied, publish the already authorized release. Read the tag, URL, asset metadata and actual bytes anonymously. The public archive must link code, Spanish report, figures, aggregate tables, manifest and acceptance evidence; confirm the version shown to readers matches the target.
3. Run canonical Phase 5 verification after public proof, then code/security review and documentation verification. Execute GSD UAT and full milestone audit over requirements, summaries, verification and integration. Fix findings with affected reruns and refresh the exact target/release readback if release bytes change. Only with a passing audit, zero material open gates and all phases verified, run administrative milestone completion; do not use an override to assert full completion.

## Gate

A draft readback proves uploaded candidate bytes but not public access. Public readback supplies REL-04 evidence; later independent Phase 5 and milestone audits supply GSD-01. If any gate remains open, preserve the preliminary release and report the precise blocked state without declaring v1.0.0 complete.
