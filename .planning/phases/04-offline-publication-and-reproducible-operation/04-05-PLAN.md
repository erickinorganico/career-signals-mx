Do not trust an arbitrary returned list as its own allowlist. `research-open` resolves CSV/Parquet as `exports/public-records.csv` or `.parquet`, and DuckDB as `exports/public.duckdb`.
- `enoe-refresh --source-root --output-root` refreshes all eight approved snapshot IDs in the fixed registry order. `--source-root` is the acquisition custody root passed as the underlying `acquire_snapshot` output root; `--output-root` is the dependent publication root, never a second raw-data destination. No arbitrary URL or new edition is introduced.
- The acceptance-to-analysis bridge must be installed and documented. Add `research-analyze --source-root --acceptance-receipt --analysis-output --audit-dir` using `pipeline_v2.analyze_acceptance` and the existing `findings_v2.build_analysis_packet`; the ignored proof script is not a runtime dependency. Reject unsafe root ancestry before writes and detect input/current changes before success. The following `research-build` consumes that persisted packet normally.
