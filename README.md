# Brújula Laboral MX

Observatorio analítico local y reproducible del mercado laboral mexicano.
**Estado: implementación en curso.** Este repositorio se está construyendo y
verificando; este primer hito preserva el alcance, la licencia y las reglas de datos.

La primera versión entrega pipelines Python, tablas DuckDB, contratos, pruebas,
gráficas, reportes y briefs con referencias. No incluye una aplicación navegable.

El piloto usa datos sintéticos identificados como tales. No son mediciones de
México y no deben usarse para elegir una carrera. Campo de estudio, ocupación y
vacante son conceptos distintos. Las ausencias permanecen `null`, nunca cero.

La investigación de fuentes precede al cálculo: toda futura carga real necesita
licencia de redistribución, población, periodo, metodología y precisión verificables.
No hay APIs pagadas, credenciales de inferencia ni hosting obligatorio.

Código y fixtures originales: [MIT](LICENSE). Los derechos y condiciones de
fuentes externas se documentan por separado antes de incorporar datos.

## English

An open-source, local-first Mexican labor research repository. The first release
provides reproducible pipelines, DuckDB models, contracts, tests, charts, reports
and evidence-backed briefs. It is not a web application. The initial pilot uses
explicitly synthetic data, not estimates of Mexico. Implementation and verification
are in progress; reproducibility instructions will be added with the verified release.
