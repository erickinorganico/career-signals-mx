# Ejemplo sintético del release 0.1.0

**DATOS SINTÉTICOS ILUSTRATIVOS.** Ninguna cifra representa estimaciones del
mercado laboral real. Snapshot estático; no es una actualización ni un current vivo.

- [Reporte Markdown](report.md): tablas, gráficas, fuentes, límites e insights.
- [Reporte HTML offline](report.html): descargar la carpeta completa y abrir el archivo.
- [Release y reproducción](../../docs/RELEASE.md).
- [Receipt de publicación y hashes](../../docs/evidence/release-receipt.json).

La carpeta conserva los bytes de los reportes del run indicado en el receipt.
El bundle completo descargable incluye DuckDB, exports, current, raw y manifest.
Para resolver una ejecución local vigente usa `python -m brujula report --output DIR`.
