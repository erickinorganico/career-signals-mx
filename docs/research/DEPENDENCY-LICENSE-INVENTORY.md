### Distribution boundary

The project wheel redistributes project-authored package resources, four DejaVu font files, and the complete `LICENSE_DEJAVU` notice. It does not redistribute the temporary Python environment or a native WeasyPrint/GTK bundle. NumPy is a direct runtime dependency; `pypdf` and pytest are test dependencies; WeasyPrint 70 is an optional PDF Python dependency. Exact final contents remain a Phase 5 frozen-inventory gate.

The reviewed native PDF asset is retained as source/CI evidence only (SHA-256 recorded in the candidate JSON), not as a redistributed asset. The historical pip-audit 0.1 result is retained as history; this refresh makes no current vulnerability claim.

### Límite de distribución

La rueda del proyecto redistribuye recursos creados por el proyecto, cuatro archivos de fuente DejaVu y el aviso completo `LICENSE_DEJAVU`. No redistribuye el entorno temporal de Python ni un paquete nativo de WeasyPrint/GTK. NumPy es dependencia directa de ejecución; `pypdf` y pytest son dependencias de pruebas; WeasyPrint 70 es una dependencia Python opcional para PDF. El contenido final exacto sigue siendo una compuerta de inventario congelado de la Fase 5.

El activo PDF nativo revisado se conserva únicamente como evidencia de fuente/CI (su SHA-256 está en el JSON candidato), no como activo redistribuido. El resultado histórico de pip-audit 0.1 se conserva como historia; esta actualización no afirma una auditoría actual de vulnerabilidades.
